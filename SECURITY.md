# Security Policy

## Supported Versions

Security updates are provided for the latest minor release on the `main` branch and the corresponding container image tags (`latest` / `vX.Y.Z`).

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| < latest | :x:               |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them privately using one of the following methods:

1. **GitHub Security Advisories** (preferred): Go to the [Security Advisories](https://github.com/mxw02/brief/security/advisories/new) page and submit a private report.
2. **Email**: Send details to **maurice.woike@gmail.com** with `[SECURITY] Brief:` in the subject line.

Please include as much of the following information as possible:

- Description of the vulnerability and its potential impact
- Steps to reproduce or a proof-of-concept
- Affected versions or deployment configurations

You can expect an initial acknowledgment within **72 hours** and regular updates as we investigate and prepare a fix.
